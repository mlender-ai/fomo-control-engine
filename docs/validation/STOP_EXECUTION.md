## 0. 결론 — 손절과 익절의 체결 규칙이 비대칭이다

```python
policy.py:360  def _stop_breached(trade, close):          # ← 종가만 본다
                   return close <= trade.stop_price

policy.py:366  def _take_profit_touched(trade, bar):      # ← 봉 중간 터치를 본다
                   return bar.high >= trade.take_profit_price
```

**익절은 봉 중간에 닿으면 그 가격에 체결되고, 손절은 봉이 닫힐 때까지 기다렸다가
종가에 체결된다.** 4시간봉에서 종가는 무효화선에서 멀리 가 있다.

이 비대칭이 초과분의 기전이다. 슬리피지 모델(`execution_cost_rate`)의 문제가 아니다 —
비용은 따로 계산되며 초과분의 18%밖에 안 된다.

## 1. −0.559R 이 어디서 오는가 (§5 작업 1)

먼저 WO 가 인용한 `−1.559R` 의 기준을 확정한다. **gross 값이다.**

| | 값 |
| --- | --- |
| 평균 grossR | **−1.559** (WO 인용값과 일치) |
| 평균 비용R | +0.122 |
| 평균 netR | **−1.681** |

계획은 −1.000R 이다. 분해:

| 요인 | R | 비중 |
| --- | --- | --- |
| **체결가가 무효화선 너머** | **−0.559** | **82%** |
| 마찰 비용 | −0.122 | 18% |
| 합계 (netR − 계획) | −0.681 | 100% |

**초과분의 82%가 체결가 이탈이다.** 비용은 부차적이다.

## 3. 산출하지 못한 것 (C9)

**종가 체결 규칙과 갭의 분리는 산출하지 못했다.**

필요한 것: 청산 봉의 OHLC. "무효화선에 봉 중간에 닿았는가, 아니면 봉 시가부터 이미
넘어 있었는가"는 `low`/`high`/`open` 없이는 판정할 수 없다.

```
market_snapshots          → 크립토 OHLC 없음
toss_candles              → 주식 전용
stance_history_candles    → 국면 판정용, 체결 검증에 부적합
```

**크립토 봉은 DB 에 보존되지 않는다 — 거래소에서 실시간 조회한다.** 그래서 사후 체결
검증이 원장만으로는 불가능하다. `POSITION_VIEW-01` 이 발견한 "국면이 저장되지 않아
사후 검증 불가"와 **같은 종류의 결함**이다.

추정치를 만들지 않았다. 요인별 정확한 기여도(갭 vs 종가 규칙 vs 감지 지연)는
**거래소 봉 조회 후에만 산출 가능하다.**

## 4. 대응 방향 (§5 작업 3~5) — 적용하지 않았다

**지배 요인은 종가 체결 규칙이다**(구조적으로 확인). 대응 방향:

### 손절도 봉 중간 터치로 체결한다

```python
# 지금            close <= stop_price          → 봉이 닫힐 때까지 기다린다
# 제안            bar.low <= stop_price        → 익절과 같은 규칙
```

- **무효화 임계를 완화하지 않는다.** 같은 가격에서, 더 일찍 체결될 뿐이다 (C1 정신 준수)
- **실제 손절 주문이 하는 일이 이것이다.** 지금 모델은 손절을 "종가 시장가"로 취급하는데
  실계좌의 스톱 주문은 봉 중간에 체결된다
- 익절은 이미 봉 중간 터치다. **모델의 비대칭이 사라진다**

> ⚠️ 종가 기준에는 **장점도 있다** — 꼬리에 털리지 않는다. 봉 중간 터치로 바꾸면
> 지금은 살아남아 이익으로 끝난 거래 일부가 손절로 바뀐다. **순효과는 반사실 없이는 모른다.**

### 갭 (SPCXUSDT)

봉 중간 터치로 바꿔도 갭은 남는다. 갭은 **수리 대상이 아니라 리스크 예산에 반영할
상수**다(WO §5 작업 4). Phase 4 와 함께 다룬다.

### 슬리피지 모델

`execution_cost_rate`(taker 0.06% + slippage 0.03%)는 초과분의 18%만 설명한다.
**모델 수정이 지배적 대응이 아니다.**

## 5. C5 — 적용은 반사실 이후다

대응을 적용하려면 **거래소 봉을 받아 반사실 재판정**을 해야 한다:

1. 8건의 청산 봉 OHLC 조회 → 갭 vs 종가 규칙 분리
2. **전체 32건**에 봉 중간 터치 손절을 적용한 재판정 — 살아남았던 거래가 손절되는 효과 포함
3. R 합계·금액·PF·MDD 대조

**이 Phase 에서는 아무것도 고치지 않았다.** 진단만 했다.

## 6. 사이징과의 관계

`POSITION_SIZING.md` Phase 1 은 1R 의 **금액가치**를 상수로 만들었다.
이 초과분은 **R 자체가 계획보다 큰** 문제이므로 사이징으로는 줄지 않는다.

```
사이징 수리 후:  −1.681R × 예산 2.5 = −4.20 USDT/건   (계획은 −2.50)
```

**계획 리스크의 1.68배를 실제로 잃는다.** 사이징이 예산을 2.5 로 잡아도 실제 리스크는
4.20 이다 — C7(리스크 확대 금지)의 관점에서 이것이 남은 구멍이다.
