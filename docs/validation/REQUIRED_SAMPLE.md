# 필요 표본 재산정 (Required Sample)

> WO-FCE-SAMPLE-RATE-01 Phase 3 정본.
> **채택 여부는 사용자 결정이다. 이 문서는 재산정 결과와 선택지만 낸다.**

## 0. 반드시 구분해야 하는 것

- **기준을 낮추는 것** = 같은 방법으로 더 적은 증거를 받아들이는 것 → **금지**
- **더 효율적인 추정량을 쓰는 것** = 같은 확신을 더 적은 표본으로 얻는 것 → 정당하다

이 문서는 후자만 다룬다. 확신 수준(검정력 80%)을 고정하고 표본 수만 비교했다.

## 1. 실측 — 그리고 불편한 발견

`backend/scripts/required_sample_analysis.py` (몬테카를로 3,000 시행 · 시드 고정 · 결정론)

엔진 승률 60% vs 벤치마크 45% (Δ=15%p), 검정력 80% 기준:

| 방법 | 필요 표본 N (팔당) | 현재 대비 | 효과 없을 때 오판율 |
|---|---|---|---|
| **M0 현재 — 두 95% CI 비겹침** | **283** | 1.00배 | 0.3% |
| M1 독립 2표본 비율검정 (α=0.05 단측) | 137 | 0.48배 | 5.6% |
| M2 페어드 McNemar (ρ=0.0 · 대조군) | 138 | 0.49배 | 5.4% |
| M2 페어드 McNemar (ρ=0.3) | 111 | 0.39배 | 4.8% |
| M2 페어드 McNemar (ρ=0.5) | **86** | 0.30배 | 4.7% |
| M2 페어드 McNemar (ρ=0.7) | **64** | 0.23배 | 5.7% |
| M3 순차검정 (4회 관찰 · Pocock 보정) | 211 | 0.75배 | 2.5% |
| M4 효과크기 (Δ≥10%p + CI 하한>0) | 174 | 0.61배 | 2.8% |

> ρ=0 대조군이 M1과 거의 같다(138 vs 137)는 것이 페어링 모델이 옳다는 확인이다.
> 페어링 이득은 상관에서만 나오며, 상관이 0이면 이득도 0이다.

### 1-1. 핵심 발견 — 30건과 현재 방법은 서로 맞지 않는다

**N=30에서 80% 검정력으로 탐지 가능한 최소 효과** (벤치마크 45% 고정):

| 방법 | 필요 엔진 승률 | 필요 효과 |
|---|---|---|
| M0 현재 (CI 비겹침) | **85%** | **40%p** |
| M1 2표본 비율검정 | 76% | 31%p |
| M2 페어드 ρ=0.5 | 72% | 27%p |
| M4 효과크기 | 79% | 34%p |

**현재 방법으로 30건에서 우위를 주장하려면 승률 85%가 필요하다.** 현실적인 트레이딩
엣지가 아니다. 즉 문제는 "표본이 느리게 쌓인다"만이 아니라 —

> **목표 30건은 게이트 축 2(성과 우위)가 요구하는 판정을 애초에 지탱하지 못한다.**

`COMPLETION_DEFINITION.md`의 표본 30건과 `LIVE_TRADING_GATE.md` 축 2의 CI 비겹침은
**서로 모순된다.** 둘 중 하나는 바뀌어야 하고, **바뀌어야 할 쪽은 게이트가 아니다.**

## 2. 왜 M0가 이렇게 많이 필요한가

두 95% CI의 비겹침을 요구하는 것은 α=5% 검정이 **아니다.** 두 구간이 각각 오차를 허용하고
그 둘이 떨어져야 하므로, 실효 유의수준은 **0.3%** 수준이다(위 표의 오판율 열).

M0은 "엄격해서 좋은" 것이 아니라 **얼마나 엄격한지 아무도 모르는 채로 엄격하다.** α를
명시적으로 고르는 것이 통계적으로 정직하다.

> ⚠️ 다만 M0 → M1은 오판율을 0.3%에서 5.6%로 **올린다.** 이것은 효율 개선이 아니라
> **확신 수준의 변경**이다. 그래서 이 문서는 채택을 권고하지 않고 선택지로만 낸다.

## 3. 현재 비교는 페어드가 아니다 — 독립이다

| 위치 | 방식 |
|---|---|
| `paper/service.py::paper_scoreboard` | 엔진 거래 집합 vs 사용자 거래 집합 — **독립** |
| `validation/live_trading_gate.py::edge_verdict` | 두 부트스트랩 CI 비겹침 — **독립** |

페어링으로 전환하려면 **짝지을 단위**가 있어야 한다. 후보: 같은 거래일 + 같은 심볼.
그런 겹침이 실제로 존재하는지는 원장을 봐야 안다.

```sql
-- 엔진·사용자가 같은 날 같은 심볼을 거래한 횟수 (페어링 가능 표본)
SELECT COUNT(*) FROM (
  SELECT substr(p.entry_bar_at,1,10) AS d, p.symbol FROM paper_trades p WHERE p.status='closed'
  INTERSECT
  SELECT substr(u.entry_at,1,10) AS d, u.symbol FROM user_trades u
);
```

겹침이 없으면 페어링은 **불가능하고**, ρ=0 행이 말하듯 이득도 없다. 그 경우 남는 선택지는
M1·M3·M4 또는 목표 N 상향이다.

## 4. 선택지 (사용자 결정)

| 안 | 내용 | 대가 |
|---|---|---|
| **A** | 방법 유지 + 목표 N을 283으로 상향 | 가장 정직하지만 검증 기간이 크게 늘어난다 |
| **B** | M1로 전환 + α를 5%로 명시 | 표본 절반. **오판율이 0.3%→5%로 오른다** |
| **C** | 페어링 가능하면 M2 | 표본 최대 1/4. 겹침 실측이 선행 |
| **D** | M4로 전환 (효과 크기 기준) | "작은 우위는 근거로 부족하다"는 입장을 명시하는 것 |
| **E** | M3 순차검정 | 조기 종료 가능. Pocock 보정 필수 |

**어느 것도 자동으로 적용되지 않는다.** 채택 시 `docs/Statistics.md`와
`COMPLETION_DEFINITION.md`에 **변경 전후를 병기**해 무엇이 바뀌었는지 추적 가능하게 한다.

## 5. 금지

- 방법 변경으로 **결과를 유리하게 만드는 것.** 방법은 데이터를 보기 전에 확정한다
  (VALIDATION-VERDICT-01 C2 승계).
- 다중 검정 보정 없는 순차 검정 — 조기 종료가 위양성 공장이 된다.
- "표본이 적으니 기준을 낮추자"는 결론. 위 표의 오판율 열이 그 판별 장치다.
- 필요 표본이 줄었다는 이유만으로 채택하기. **오판율이 함께 오르면 그건 효율이 아니다.**
