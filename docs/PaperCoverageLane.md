# 커버리지 레인 (Paper Coverage Lane)

> WO-FCE-ENGINE-RESTORE-01 정본. **표본이 부족할 때 조정할 곳은 여기지, 엄격 게이트가 아니다.**

## 목적

엄격 게이트(entry_score·RR·checklist·confirmed_flip)를 통과하는 후보는 드물다. 그런데 검증에는
체결 표본이 필요하다. 커버리지 레인은 이 둘을 **분리**한다.

- 엄격 레인: 실제 성과 판정용. 게이트를 전부 통과한 것만.
- **커버리지 레인**: 체결 표본 축적용. 엄격 게이트를 우회하되 **소액**(자본 0.5%)으로 진입하고,
  `execution_sample_only_not_strict_performance` 태그를 달아 **성과 집계에서 분리**한다.

즉 "느슨하게라도 돌려보는 것"은 이미 설계·구현·활성화되어 있다(`stock-v4.json`).

| 파라미터 | 현재값 | 뜻 |
| --- | --- | --- |
| `coverage_entry_enabled` | true | 레인 활성 |
| `coverage_target_open_positions` | 3 | 동시 보유 목표 |
| `coverage_position_capital_fraction` | 0.005 | 건당 자본 0.5% |
| `coverage_max_attempts_per_cycle` | 3 | 사이클당 시도 상한 |

## 표본이 부족할 때 — 정답과 오답

| | 조치 | 결과 |
| --- | --- | --- |
| ✅ 정답 | 커버리지 레인 처리량 상향(목표 포지션·시도 수), 유니버스 확대, 타임프레임 추가, 관측 기간 연장 | **같은 잣대로 더 많이 잰다** |
| ❌ 오답 | RR 1.5→0.5, entry_score 75→65, 체크리스트 완화, 무효화가·확률 근거 요건 완화 | **잣대 자체가 바뀐다** |

오답을 선택하면 4주 뒤 나오는 성적은 "완화된 기준에서의 성적"이라 **자동매매 판단 근거로 쓸 수 없다.**
엄격 게이트 인하는 영구 금지다(WO C1).

## 착수 조건

표본 부족을 이유로 이 레인의 처리량을 조정하려면, 먼저 **엔진이 무중단으로 돌아간 구간의 실측**이
있어야 한다. 멈춘 엔진 위에서 파라미터를 바꾸면 바꾼 효과조차 관측되지 않는다.
